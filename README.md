# GramSahayak — SIH 26091, Team Nexora

Tamil Nadu-first rural business planning prototype. React interface, FastAPI backend, a **trained small business-text classifier**, local document retrieval, optional API generation and a downloaded **Qwen3 0.6B local LLM**. Financial arithmetic is deterministic Python, never generated by the LLM.

## Run on this machine

From the `Nexora` folder:

```powershell
.\start.ps1
```

Open **http://127.0.0.1:8000**. Keep the terminal open. Guest use needs no login or API key. Local accounts are available under My account. The existing production build, classifier, datasets and local LLM weights are present. The local server must remain running to calculate new plans. After one successful load, the browser can reopen its last saved plan even if the server stops.

If PowerShell blocks scripts, use:

```powershell
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

## Fresh installation

Requirements: Node.js 22.12+ (24 LTS recommended), Python 3.11–3.14, about 4 GB free disk and 4–6 GB available RAM for the local model. Python 3.14, CPU-only Torch 2.9 and Transformers 5.15.1 were used here. The trained sklearn artifact requires sklearn 1.7.2; retrain after intentionally changing that version.

```powershell
cd Nexora
python -m venv .venv
.\.venv\Scripts\python -m pip install -r backend\requirements-local-llm.txt
cd frontend
npm ci
npm run build
cd ..
.\start.ps1
```

For a lighter installation without local generation, install `backend/requirements.txt`; set `LOCAL_LLM=0`. The trained classifier, RAG, all calculations and curated multilingual guidance still work. This reduced mode must not be described as local LLM generation.

Model weights are downloaded in this working folder. If transferring via Git, weights are intentionally ignored. Download them once on the new machine:

```powershell
.\.venv\Scripts\python scripts\download_model.py
```

The download is about 1.5 GB, Apache-2.0 licensed. Normal local inference uses `local_files_only=True` and offline environment settings. Do the download before disconnecting the demo laptop.

## Configuration

Copy `.env.example` to `.env` in `Nexora/`. The backend reads it; restart the server after changes. **Never put provider keys in VITE variables.**

```dotenv
# Optional OpenAI-compatible chat-completions provider. Leave empty for local-only.
LLM_BASE_URL=
LLM_API_KEY=
LLM_MODEL=
# 1 enables downloaded Qwen3 fallback; 0 disables it.
LOCAL_LLM=1
LOCAL_LLM_TIMEOUT=150
```

`LLM_BASE_URL` is the provider's API root ending in `/v1` if required by that provider. The backend appends `/chat/completions`. No live external API was tested because no key was supplied; structured-response, failure and fallback behavior is tested locally. A configured provider receives the business description, district, category and retrieved document excerpts, not margin amounts or personal identity.

Advice flow: API → local open model → curated, fully translated guidance. Each response must satisfy the JSON schema and language checks. The local model was actually run and its English JSON validated (82 seconds on this CPU). Reports appear immediately with curated guidance while optional generation runs in the background. The interface identifies the provider/fallback; generated text is kept separately for English, Tamil and Hindi. Exact prompt results are cached in SQLite. Rapid language changes may queue generation; the translated base report is always immediate.

## Financial rules and assumptions

- Project cost = own margin / 0.10; indicative financing = 90% of project cost.
- Project ≤ ₹1,40,000: Micro Finance, 6.5% p.a., 36 months **including** 3 months moratorium; loan capped at ₹1,25,000.
- ₹1,40,000 < project ≤ ₹50,00,000: Term Loan, 8% p.a., 84 months **including** 6 months moratorium; loan capped at ₹45,00,000.
- Above ₹50 lakh: no scheme loan is allocated, and the funding gap is shown. Invalid, negative, non-finite or zero inputs are rejected. Margin is bounded at ₹10 crore for numerical and UI safety.
- Simple grace-period interest accrues without payment and is capitalised once. Afterwards, quarterly reducing-balance instalments use nominal annual rate / 4. First payment is due at the end of month 6/9; final payment at month 36/84. The final payment clears rounding residue to exactly zero.
- At ₹14,000 margin, project ₹1,40,000, 90% finance ₹1,26,000 but loan cap ₹1,25,000; **additional own funds ₹1,000** are explicit.
- The moratorium capitalization policy is an assumption, not an assertion about every sanctioning agency. Confirm the lender's exact terms.
- A route is not eligibility approval. NSFDC's target community and income/agency conditions apply. TAHDCO/BC welfare links are guidance, not submitted applications. No fabricated bank branches, credit scores or guaranteed subsidies.

Operating cost, working capital, sales ramp, break-even units and downside sensitivity are **scenario estimates**. The plan never forces profits to be positive. Financing envelope is not a recommendation to borrow the maximum. The cash-flow projection assumes the project is fully funded; funding-gap warnings must be resolved first.

## Two-minute panel demo

1. **0:00–0:25** — Open the app. Choose **Try a dairy example**: `Alanganallur, Madurai / ₹1,00,000 / Fresh milk and curd delivery`. Generate. State: "Tamil Nadu default, a trained classifier, and local evidence; these market figures are labelled estimates."
2. **0:25–0:50** — Show market reach, SWOT, competitors and pricing. Point out that competition is a density scenario, not invented shops. The default dairy scenario may show tight cash: this is useful risk guidance, not a failed calculation. Open more options and declare an existing workspace only if that assumption is appropriate.
3. **0:50–1:15** — Open **Financial plan**, then **Repayments**: project **₹10,00,000**, loan **₹9,00,000**. Show two zero-payment quarters and the first repayment at month 9. Change margin to **₹14,000**: micro route, **₹1,25,000** loan and **₹1,000** extra equity gap. Change to **₹5,00,001** to demonstrate the outside-limit warning.
4. **1:15–1:40** — Switch to **தமிழ்**, then **हिन्दी**. All report labels, assumptions, calculations and print content switch immediately. Original user-entered text and official place names retain their source spelling.
5. **1:40–2:00** — Open **Data & assumptions**, show source links and the model evaluation caveat. Use **Print / save PDF**. Disconnect external internet while leaving the local server running, then regenerate another plan. If the server also stops, reload to show the last cached report.

Extra inputs: `Coimbatire / ₹25,000 / mobile phone repair`; `மதுரை / ₹20,000 / தையல் கடை`; `मदुरै / ₹30,000 / किराना दुकान`. Unknown villages: add the district; ambiguous `Pudur` asks for clarification. A novel business can be accepted under “Other” with an uncertainty warning instead of a false confident label.

## Verify / retrain

```powershell
python -m unittest discover -s backend -p "test_*.py" -v
python ml/train.py
cd frontend
npm run check:i18n
npm run build
```

Browser tests require Playwright (`npm install --no-save playwright`) and Chrome/Edge. Run the server, then `node scripts/browser-test.cjs`; set `BROWSER_PATH` if necessary. `PLAYWRIGHT_PATH` can point to an existing installed Playwright module. Tests generate visual QA files and use temporary independent browser storage.

Training: 187 project-authored multilingual phrases → 641 training examples after deterministic augmentation. **48 independent-phrase holdout examples: accuracy 1.0, macro F1 1.0.** This small curated test is not a representative real-world benchmark, language fluency metric, feasibility accuracy or business success probability. Training data, test phrases, seed, per-class metrics and training script are included. Qwen is pretrained; no claim of training a large model is made.

## Known limitations

- All 38 districts are supported. Blocks/panchayats come from an **older official directory**, remapped with a curated crosswalk; current LGD boundaries are not fully verified. Source counts differ from current administrative totals. These are not 12,620 current validated village surveys.
- No village-level population, income, observed competitor survey or live mandi/Aavin price feed was acquired. Local prices, density, purchasing-power indexes and sales are explicit synthetic planning priors. Government directories and NABARD text are real cached evidence; do not call the numerical estimates surveyed facts.
- Free text, aliases, spelling errors and three scripts are supported, but arbitrary village/business recognition is not guaranteed. Unknown places need a district; unknown categories produce a generic cautious scenario. Native-speaker translation review remains advisable before public release.
- Small local LLM generation can be slow and imperfect, especially Tamil; invalid/mixed-language output is rejected in favour of translated curated guidance. No system can guarantee correct advice for every input. Live API quality remains unverified without credentials.
- Optional street-map tiles/reverse geocoding and browser voice recognition need their providers and may fail offline. Text location entry, cached evidence, models and all calculations remain local. Browser-only offline mode restores the last report; a running backend is required for new calculations.
- Print-to-PDF uses the browser dialog. The UI and fonts are localized; browser/OS-owned dialog wording follows the device settings. Tables are also downloadable as localized CSV.
- This is a local demo, not a public multi-user service: local accounts protect saved workspaces, but anonymous report URLs, device caches and absent production quotas make this unsuitable for public multi-user deployment. Do not deploy the local SQLite demo publicly unchanged.

See `audit/ANALYSIS.md`, `audit/VERIFICATION.md`, and `data/DATA_SOURCES.md` for the full audit and evidence.
